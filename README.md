One funny line, one sentence, at most 200 characters. `main.ts` writes
the line exactly — no trailing newline — to `/output/entry.txt`.

## The line

> I bought noise-cancelling headphones for silence, and now I can hear my own thoughts, which is not the silence I ordered.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). Stdlib
only; no network, no randomness, no secrets. The output is byte-identical
on every run: 121 characters, 121 bytes, one sentence.

## Why this line

Buying silence and getting your own thoughts instead: the surprise is
the very last clause, the everyday truth (headphones bought for quiet)
is immediate, and no word explains the joke.
